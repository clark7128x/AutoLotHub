# API Reference

Базовий URL: `/api/v1`

## 1. Автентифікація (`/auth`)
*   **`POST /auth/register`** — Відкрита реєстрація нового Дилера (користувач автоматично отримує роль `Dealer`). Адміни та Менеджери створюються виключно через внутрішню панель (суперюзером).
*   **`POST /auth/login`** — Отримання JWT токенів (`access_token`, `refresh_token`).
*   **`POST /auth/refresh`** — Оновлення `access_token` за допомогою дійсного `refresh_token`.
## 2. Користувачі (`/users`)
*   **`GET /users/me`** — Отримання інформації про поточного користувача.
*   **`GET /users`** — Список користувачів (тільки для Admin/Manager).

## 3. Автомобілі (`/cars`)
*   **`GET /cars`** — Список авто (доступно всім, підтримує пагінацію `limit`/`offset` та фільтр за `status`).
*   **`POST /cars/decode-vin`** — (Інтеграція, Admin, Manager) Передається `{"vin": "..."}`. Повертає розширені дані від Mock API.
*   **`POST /cars`** — Створення лоту (Admin, Manager).
*   **`PATCH /cars/{car_id}`** — Оновлення ціни або статусу авто.
*   **`DELETE /cars/{car_id}`** — Видалення лоту (Admin).

## 4. Замовлення (`/orders`)
*   **`GET /orders`** — Список замовлень. Дилери бачать тільки свої.
*   **`POST /orders`** — Створення нового замовлення (бронювання авто).
*   **`PATCH /orders/{order_id}/status`** — Зміна статусу замовлення (Admin, Manager).
