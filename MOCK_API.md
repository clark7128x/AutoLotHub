# Специфікація Mock API VIN-декодера

Цей документ описує внутрішній сервіс (адаптер), який імітує звернення до зовнішнього API для декодування VIN-кодів. 

## Архітектурний підхід (External Service Adapter)
Для забезпечення гнучкості та відповідності принципам Clean Architecture, цей функціонал виділено в ізольований шар — `app/external_services`.
Основний бекенд (сервіси лотів) не знає, звідки беруться дані. Він лише викликає метод інтерфейсу `decode_vin(vin: str) -> ExternalCarDataDTO`. 
Завдяки цьому, коли проєкт буде готовий до продакшену, заміна цього моку на реальний зовнішній сервіс (наприклад, NHTSA vPIC) потребуватиме лише створення нового класу-адаптера, **без жодних змін у бізнес-логіці чи моделях БД**.

## Формат взаємодії
Оскільки це мок-сервіс для MVP, він працює як внутрішня Python-функція, що імітує мережеву затримку (`await asyncio.sleep(2)`) і повертає Pydantic-схеми, або кидає специфічні винятки, що перехоплюються обробником помилок у FastAPI.

### 1. Успішна відповідь: "Чисте" авто
* **Сценарій:** Передано валідний VIN-код звичайного автомобіля.
* **Повертається код HTTP:** `200 OK`
* **Тіло відповіді (JSON):**
```json
{
  "success": true,
  "data": {
    "vin": "1HGCM82633AXXXXX1",
    "make": "Honda",
    "model": "Accord",
    "year": 2018,
    "country": "Japan",
    "history_status": "CLEAN",
    "engine": "2.4L I4"
  }
}
```

### 2. Успішна відповідь: Автомобіль після ДТП / Торгів
* **Сценарій:** Передано валідний VIN-код автомобіля, що продавався на аукціонах у стані "Salvage".
* **Повертається код HTTP:** `200 OK`
* **Тіло відповіді (JSON):**
```json
{
  "success": true,
  "data": {
    "vin": "5YJ3E1EA3JXXXXXX2",
    "make": "Tesla",
    "model": "Model 3",
    "year": 2020,
    "country": "USA",
    "history_status": "SALVAGE_AUCTION",
    "damage": "Front End",
    "engine": "Electric"
  }
}
```

### 3. Помилка: Невалідний формат VIN
* **Сценарій:** Передано рядок, що не відповідає стандарту VIN (наприклад, менше 17 символів або містить заборонені літери I, O, Q).
* **Повертається код HTTP:** `400 Bad Request`
* **Тіло відповіді (JSON):**
```json
{
  "success": false,
  "error": {
    "code": "INVALID_VIN",
    "message": "Введено некоректний VIN код. Довжина має бути 17 символів, без літер I, O, Q."
  }
}
```

### 4. Помилка: VIN не знайдено (Not Found)
* **Сценарій:** Передано валідний за форматом VIN, але його немає в уявній базі мока (імітація відсутності даних на аукціоні).
* **Повертається код HTTP:** `404 Not Found`
* **Тіло відповіді (JSON):**
```json
{
  "success": false,
  "error": {
    "code": "VIN_NOT_FOUND",
    "message": "Дані по автомобілю з таким VIN не знайдено в реєстрах."
  }
}
```
